# Figures

- `orai1_stim1_hexamer_cad_pLDDT.png` / `.pdf` — Boltz-2 prediction of the
  Orai1 hexamer (chains A–F) bound to twelve copies of the STIM1
  CRAC-activation domain (CAD, chains G–R), colored by per-residue pLDDT
  confidence. Top view and side view. Used as the repo-root README's
  overview figure. The `.pdf` is the original vector figure; the `.png` is
  a rasterized copy for Markdown rendering on GitHub.
